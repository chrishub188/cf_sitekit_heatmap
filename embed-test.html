Watch the Network panel for /api/grid. With no sessionId set, expect one request on load and then roughly one per 40 m walked — never one per pose, and none at all while turning in place. Only PET has a tuned colour ramp; the other grid types will look wrong. Planting or clearing an intervention, or applying a sessionId, should each trigger exactly one new request right away, independent of the walking pacing. Once a sessionId is applied, walking should stop triggering new requests entirely — the request has no coordinate in it any more, so there's nothing for movement to affect; only a changed sessionId or interventions list should fetch again. Clear the sessionId field and re-apply an empty value to switch back to normal walking-based requests.
